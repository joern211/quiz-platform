# v0.3.0 Scope — Vertikaler Schnitt: Geo-Quiz

**Ziel:** Ein vollständig spielbarer, sicherer, getesteter Geo-Quiz-Multiplayer-Flow.
**Status:** Prototyp — nicht produktionsbereit.

---

## Was in v0.3.0 fertig sein muss

| # | Anforderung | Status |
|---|---|---|
| 1 | Frischer Clone installiert reproduzierbar ohne manuelle Eingriffe | ❌ |
| 2 | Datenbank-Migration + Seed laufen auf leerer DB wiederholbar | ❌ |
| 3 | Web-Build UND Server-Build laufen erfolgreich | ❌ |
| 4 | Unit/Integration/Playwright-Tests laufen (kein Watch-Modus) | ❌ |
| 5 | Docker startet ohne manuelle Korrekturen | ❌ |
| 6 | Moderator kann sich anmelden, Geo konfigurieren, Raum erstellen | ❌ |

## Was NICHT in v0.3.0 erwartet wird

- Weitere Spiele (Jeopardy, Wer ist das, Timeline, Lügen, Song) als vollständige Engines
- Produktions-CSRF-Protection mit Token
- Echte PWA-Installierbarkeit mit Update-Strategie
- Automatische Backups

---

## Gates (Reihenfolge ist strikt)

```
Gate 0 → Gate 1 → Gate 2 → Gate 3 → Gate 4 → Gate 5 → Gate 6 → Gate 7 → Gate 8
```

**Kein Gate wird übersprungen. Ein Gate gilt erst als bestanden, wenn alle Abnahmekriterien erfüllt sind.**

---

## Spielstand nach Gate 0

- **Geo-Quiz:** PLANNED → BETA (wird mit Gate 4–5 vollständig)
- **Jeopardy:** AVAILABLE → PLANNED
- **Wer ist das?:** AVAILABLE → PLANNED
- **Timeline:** AVAILABLE → PLANNED
- **Wer lügt am besten?:** AVAILABLE → PLANNED
- **Erkenne den Song:** AVAILABLE → PLANNED

Nur Geo hat einen vollständigen End-to-End-Nachweis in v0.3.0. Alle anderen Spiele sind dementsprechend markiert.

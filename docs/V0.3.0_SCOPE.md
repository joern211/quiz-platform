# v0.3.0 Scope — Vertikaler Schnitt: Geo-Quiz

**Ziel:** Ein vollständig spielbarer, sicherer, getesteter Geo-Quiz-Multiplayer-Flow.
**Status:** 🔄 IN ARBEIT — noch nicht produktionsreif.
**Branch:** `gate-1-2-fixes`

> Nur Geo-Quiz hat einen vollständigen End-to-End-Ablauf in v0.3.0.
> Andere Spiele (Jeopardy, Wer ist das, Timeline, Lügen, Song) sind `PLANNED`.

## Was NICHT in v0.3.0 erwartet wird

- Weitere Spiele als vollständige Engines
- Produktions-CSRF-Protection mit Token
